# 人生旁白 LifeNarrator

[English](README.md) | **简体中文**

> 给你的人生配一个旁白。

人生旁白是一款轻量的 macOS 菜单栏应用。它会看你屏幕上正在发生什么，在当前活动窗口上弹出可爱的小旁白：彩色手写字体，配一点表情，再加一点态度。

- 打开钉钉 → "又要上班了！😩"
- 打开领导的聊天框 → 框住领导的名字，旁边写着"猪领导🐷"
- 告诉它一句"我讨厌谷歌"→ 以后每次打开谷歌，它都替你吐槽。

![测试聊天窗口上框住的名字和"猪领导"旁白](docs/images/boss-bubble.png)

> **当前状态：** v0.1 预览版，可以在 [Releases](https://github.com/zygs1083-dotcom/LifeNarrator/releases) 下载 `LifeNarrator.zip`。

## 功能

- **实时，就在活动窗口上**：旁白出现在你正在用的窗口旁边，或者直接出现在它吐槽的那段文字上，窗口移动时跟着走。
- **自定义规则**：用快捷键唤出全局输入框，用大白话描述你喜欢或讨厌什么，比如"我讨厌开会""张三是我领导"。人生旁白会把它变成规则，在屏幕上出现相关内容时做出反应。
- **旁白样式随你调**：停留时长、渐隐和弹出动画、同屏最多几条、大小、形状（圆角气泡、云朵、对话框、贴纸、便签）、艺术字效果、配色主题、表情多少、人设（毒舌、温柔、中二）。
- **不装模型也能用**：内置台词包覆盖常用的应用和网站。
- **模型自己选**：安装后可以下载内置引擎，也可以接任何 OpenAI 兼容的 API 或本地服务（Ollama、LM Studio）。快速决策使用 [System One](https://docs.typesafe.ai/concepts/system-one) 类模型，比如 Jev 或开源替代品，通过 `/v1/systemone` 接口接入。
- **中英双语**：界面和台词都支持英文和简体中文。

## 为轻量而设计

- 事件驱动：屏幕上没有变化时，它什么都不做。
- 优先通过辅助功能接口读取文字，只在必要时截图做本机 OCR，窗口没变化就跳过。
- 台词提前生成并缓存，弹出时不用等模型。
- 不打包模型和字体，直接使用 macOS 自带的可爱字体。
- 在 M1 Max 上实测：空闲时内存 22MB、CPU 0%。内置模型（Qwen3.5-4B，下载 2.7GB）只在编写规则和台词时加载，空闲 5 分钟后释放。

## 隐私

默认所有处理都在你的 Mac 上完成。屏幕文字不会写日志或保存到磁盘，也永远不读密码框。如果你接入云端 API，应用会明确提示屏幕文字将被发送出去。

## 系统要求

- macOS 14 Sonoma 或更高版本
- Apple 芯片
- 辅助功能权限（必需），录屏权限（可选，用于读取不提供文字信息的应用）

## 安装和使用

1. 在 [Releases](https://github.com/zygs1083-dotcom/LifeNarrator/releases) 下载 `LifeNarrator.zip`，解压后把 `LifeNarrator.app` 拖进"应用程序"。
2. 应用暂时没有 Apple 开发者签名。macOS 14 上右键点击它并选择"打开"；macOS 15 上先打开一次，再到"系统设置 → 隐私与安全性"里点"仍要打开"。
3. 在欢迎窗口里选择模型方式，并授予辅助功能权限。
4. 按 **⌥⇧N**（或点菜单栏图标）输入"我讨厌谷歌""张三是我领导"之类的话。**⌥⇧P** 暂停旁白。

每次构建的临时签名都不同，更新后 macOS 可能忘记辅助功能权限。如果旁白不再出现，请在"隐私与安全性 → 辅助功能"里移除人生旁白再重新添加。

## 从源码构建

```sh
swift build
scripts/bundle.sh   # 需要 Xcode；生成 dist/LifeNarrator.app 和 dist/LifeNarrator.zip
```
