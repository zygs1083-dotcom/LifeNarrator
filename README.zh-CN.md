# 人生旁白 LifeNarrator

[English](README.md) | **简体中文**

> 给你的生活配一个旁白。

人生旁白是一款小巧的 macOS 菜单栏应用，里面住着一只吵闹的小精灵。每次切换窗口，它都会读一遍屏幕上的内容，用轻松明亮的细框圈出值得吐槽的地方，在旁边小声说一句。

- 商品页写着"限时直降 ¥300" → *"先涨再降的老把戏？"*
- 打开领导的聊天窗口 → 名字被框起来，旁边写着 *"猪领导🐷"*
- 跟它说一次 *"我讨厌谷歌"* → 以后谷歌一出现，它就替你吐槽。

![测试聊天窗口上框住的名字和"猪领导"旁白](docs/images/boss-bubble.png)

> **当前状态：** v0.7 预览版，可以在 [Releases](https://github.com/zygs1083-dotcom/LifeNarrator/releases) 下载 `LifeNarrator.dmg`。

## 功能

- **看懂再说。** 有模型时，小精灵会读一遍屏幕上的文字，弄清你在看什么，挑几处值得说的地方，针对每一处写一句。它圈的就是它说的那几个字；在屏幕上找不到原文，就不说。
- **就在文字旁边。** 细框圈在原文上，旁白放在旁边的空白处；滚动页面或移动窗口时一起跟着文字走，文字滚出视野时标记随之消失。每条的颜色随机，都是轻松明亮的清色。
- **知道什么时候闭嘴。** 打字时、密码框里、看全屏视频时、在你排除的应用里都不出声。同一处半小时内不会重复标。
- **自己的规则。** 按 ⌥⇧N，用大白话说你喜欢或讨厌什么，比如"我讨厌开会""张三是我领导"。规则命中时总是最先出现。
- **想怎么调就怎么调。** "热闹程度"（安静 / 热闹 / 吵闹）决定说多少；出场间隔、停留时长、同屏最多几条都是滑块。形状、配色、字体、表情和三种人设（毒舌、温柔、中二）都能改。
- **不装模型也能用。** 离线台词包覆盖常用的应用和网站，只标有把握的地方（你的规则、聊天对象、价格、按钮、截止时间）。
- **模型自己选。** 安装后可以下载内置引擎（Qwen3.5-4B，2.7GB），也可以接任何 OpenAI 兼容的 API 或本地服务（Ollama、LM Studio）。
- **中英双语。** 界面和旁白都支持英文和简体中文。

## 轻量与隐私

- 事件驱动：屏幕没变化时什么都不做。空闲时内存约 22MB、CPU 0%（M1 Max 实测）。
- 通过辅助功能接口读文字；只有拿不到精确位置的换行段落才截图做本机 OCR。
- 用内置模型时，切换后约 3–5 秒出现第一条。每分钟最多请求 4 次，低电量模式下不请求；切走立即停止，空闲 10 分钟后释放模型。
- 默认全部在本机处理。屏幕文字不写日志、不落盘；输入框和密码框的内容永远不送出，邮箱、电话、网址在交给模型前就去掉了。接云端 API 时，设置里会写清楚会发送什么。

## 系统要求

- macOS 14 Sonoma 及以上，Apple 芯片
- 辅助功能权限（必需）；录屏权限（可选，用于 OCR）

## 安装

**方式一：DMG。** 从 [Releases](https://github.com/zygs1083-dotcom/LifeNarrator/releases) 下载 `LifeNarrator.dmg`，打开后把 `LifeNarrator.app` 拖到“应用程序”快捷方式上。应用使用自签名证书，尚未公证：macOS 14 上右键点它选“打开”；macOS 15 及以上先打开一次，再到“系统设置 → 隐私与安全性”里点“仍要打开”。

**方式二：一行命令。** 在终端运行：

```sh
curl -fsSL https://raw.githubusercontent.com/zygs1083-dotcom/LifeNarrator/main/scripts/install.sh | bash
```

脚本会下载最新版本、校验 SHA-256、请正在运行的应用退出，安装到 `/Applications`（不可写时装到 `~/Applications`），去掉隔离属性并打开应用，因此不用去系统设置放行。要安装指定版本，把末尾的 `bash` 换成 `LIFENARRATOR_VERSION=vX.Y.Z bash`。

在欢迎窗口选好模型，授予辅助功能权限。录屏权限是可选的；如果开关已经打开却仍然不生效，在权限列表里把人生旁白删掉再重新添加，或从应用的权限提示卡片复制重置命令，在终端运行。

人生旁白只在菜单栏显示，没有程序坞图标。**⌥⇧N** 添加规则，**⌥⇧P** 暂停小精灵。菜单栏太满放不下图标时（带刘海的 MacBook 上很常见），从“应用程序”或聚焦搜索再打开一次人生旁白，就会弹出设置窗口。

**更新：** 在“设置 → 通用”里点“检查更新 → 立即更新”。默认启动时和每隔 24 小时自动检查，也可以在这里关闭。应用会校验下载包的 SHA-256，并确认新包满足当前应用的指定签名要求，再替换并重启。发布版使用同一张证书，辅助功能和录屏权限会保留。从 v0.1.4 之前的版本更新时，需要在权限列表里把人生旁白删掉再重新添加一次。
